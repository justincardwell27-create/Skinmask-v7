Skin Mask Mobile V7

Automatic character-art censoring with foreground filtering, eye coverage, and feathered mask edges. No CDN imports.

Runs in your browser. Uses offline illustration-aware detection and optional built-in browser face detection. This is not a trained character-segmentation AI model.

1. Automatic detection

Foreground-aware filtering attempts to exclude plain backgrounds and implausibly large warm-colored objects. Hats, tails, clothing, and unusual palettes may still cause errors; this is not trained AI character recognition.

2. Optional correction

Manual tools are just for fixing misses. Automatic censoring remains the default.
